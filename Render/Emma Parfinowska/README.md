# F20GA
The fist sections on designing the model is starting whith a sphere then using the 'clay' and 'elestic' tool to change the shape of the body. My idea is to create the main shape of Mew then be able to rig the body and be able to pose with it. 

So after shaping the body i extended parts to make up the arms and legs. I then attached 3 cones to the end of the arms to create fingers for Mew.
